# BreastScan AI

## Overview
BreastScan AI is an AI-powered web application developed for breast tumor detection and medical scan analysis. The system supports mammography, ultrasound, and MRI scan images to assist in the early detection of breast cancer.

The application provides AI-based analysis including tumor classification, BI-RADS assessment, confidence scoring, and clinical recommendations through an interactive and user-friendly interface.

---

## Features
- Breast scan image upload
- Mammography support
- MRI scan analysis
- Ultrasound scan support
- AI-based tumor detection
- BI-RADS classification
- Malignancy prediction
- Confidence score analysis
- AI medical assistant chatbot
- Clinical recommendation system
- Scan history management
- Report generation interface

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## Project Workflow
1. Upload breast scan image
2. Image preprocessing
3. AI-based image analysis
4. Tumor classification
5. BI-RADS assessment
6. Clinical recommendation generation
7. Result visualization

---

## Objective
The main objective of this project is to support early breast cancer detection using Artificial Intelligence and improve medical diagnostic efficiency through smart medical image analysis.
